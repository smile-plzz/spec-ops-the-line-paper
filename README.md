# Spec Ops: The Line — Interdisciplinary Academic Research Project

## Project Overview
This repository contains the complete academic research investigation, evidence matrices, review records, and full manuscript for the study:
**"Do You Feel Like a Hero Yet? Narrative Deception, Moral Complicity, Psychological Deterioration, and the Ethics of Play in Spec Ops: The Line"**

Primary Discipline: Game Studies  
Secondary Disciplines: Media Studies, Narrative Studies, Psychology of Interactive Media, Moral Philosophy, Cultural Studies, Digital Humanities  
Citation Style: APA 7th Edition  
Target Manuscript Length: 7,000–9,000 words (excluding references & appendices)  
Research Infrastructure: `academic-research-skills` (v3.24.1 pipeline specification)

## Workflow & Deliverables Directory Structure
- `00_PROJECT_README.md`: Project summary, workflow stages, and deliverables index.
- `01_RESEARCH_BRIEF.md`: Core research questions, theoretical architecture, and scope.
- `02_SEARCH_STRATEGY_AND_LOG.md`: Search queries, academic database records, screening decisions.
- `03_ANNOTATED_BIBLIOGRAPHY.md`: Verified peer-reviewed literature, primary developer documents.
- `04_LITERATURE_SYNTHESIS.md`: Thematic state of research, debates, and identified gaps.
- `05_SCENE_ANALYSIS_MATRIX.md`: Chronological & thematic ludonarrative scene-level matrix.
- `06_CHARACTER_ANALYSIS_MATRIX.md`: Comprehensive character arcs & multidimensional analysis.
- `07_EVIDENCE_AND_CLAIM_MATRIX.csv`: Traceable claim-to-evidence verification database.
- `08_FULL_RESEARCH_PAPER.md`: Final full-length peer-reviewed academic manuscript (7,000–9,000 words).
- `09_PEER_REVIEW.md`: Multi-perspective 5-seat peer review & Devil's Advocate report.
- `10_REVISION_AND_INTEGRITY_REPORT.md`: Point-by-point response, 7-mode AI integrity audit, APA 7 verification.
- `11_PROCESS_RECORD.md`: Procedural state machine and collaboration audit.
- `references.bib`: BibTeX export of all cited literature.
